## Технические детали / Technical Details

### Стратегия кэширования / Caching Strategy
```
Cache-First (Offline-First)
├── Проверка кэша
│   ├── Найдено → Возврат из кэша
│   └── Не найдено → Запрос к сети
└── Сохранение в кэш для будущего использования
```

## Тестирование / Testing

### Проверка Service Worker / Service Worker Check
```javascript
// Откройте консоль браузера
navigator.serviceWorker.getRegistration().then(reg => {
  console.log('Service Worker:', reg ? 'Зарегистрирован ✅' : 'Не найден ❌');
});
```

### Проверка кэша / Cache Check
```javascript
// Откройте консоль браузера
caches.keys().then(keys => {
  console.log('Кэши:', keys);
});
```

### Тест оффлайн / Offline Test
1. Загрузите приложение один раз
2. Откройте DevTools → Network
3. Включите "Offline"
4. Перезагрузите страницу
5. ✅ Приложение должно работать!

### Тест мобильных настроек / Mobile Settings Test
1. Откройте DevTools (F12)
2. Включите режим устройства (Ctrl+Shift+M)
3. Выберите мобильное устройство
4. Откройте настройки
5. ✅ Настройки должны быть адаптивными!

## Как использовать / How to Use

### Для разработки / For Development
1. Откройте `index.html` в браузере
2. Service Worker зарегистрируется автоматически
3. Приложение готово к работе оффлайн

### Для тестирования / For Testing
1. Откройте `pwa-test.html`
2. Проверьте все компоненты PWA
3. Протестируйте оффлайн режим

### Для установки / For Installation
1. Откройте приложение в браузере
2. Нажмите кнопку "Установить" (или меню → "Добавить на главный экран")
3. Приложение установится как нативное
